## Sobre o projeto

O Wolf System Diagnostic PRO é um aplicativo
de desktop desenvolvido em Python para
monitoramento de recursos e diagnóstico
básico de computadores.

O projeto foi desenvolvido como parte da minha
jornada de aprendizado em programação e
Suporte de TI, com auxílio de Inteligência
Artificial.

## Funcionalidades

- Monitoramento de CPU em tempo real.
- Monitoramento de memória RAM.
- Monitoramento de armazenamento.
- Informações do sistema operacional.
- Identificação da arquitetura.
- Indicadores circulares de utilização.
- Alertas de consumo elevado.
- Exportação de relatórios em TXT.
- Interface gráfica preta e vermelha.
- Atualização automática e manual.

## Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| Python | Linguagem de programação |
| Tkinter | Interface gráfica |
| Psutil | Monitoramento de recursos |
| Platform | Informações do sistema |
| Datetime | Data e horário dos relatórios |
| GitHub | Versionamento e documentação |

## Instalação

Requisitos:

- Windows
- Python instalado
- Tkinter disponível

Baixe os arquivos deste repositório.

Abra o terminal na pasta do projeto e instale
as dependências:

```bash
python -m pip install -r requirements.txt
```

## Executar o aplicativo

Interface gráfica:

```bash
python dashboard.py
```

Versão pelo terminal:

```bash
python main.py
```

## Testes e limitações

A interface gráfica e a exportação de relatórios
foram testadas em Windows 10.

O aplicativo monitora a ocupação do disco do
sistema e não realiza reparos no computador.

Os alertas indicam utilização elevada dos
recursos, não necessariamente defeitos.
